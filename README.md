# Daron L. Brown Website

<!-- repo-intro:start -->
**Project snapshot:** A React-based personal/professional website project built to present Daron L. Brown through a responsive, multi-page web experience rather than a framework starter template.

<!-- repo-intro:end -->

## Project purpose

This repository contains the custom React site built for **Daron L. Brown**. It is maintained as a client-facing website project and as an example of adapting a standard React foundation into a purpose-built web presence.

## Stack

- React 19
- React Router
- Create React App toolchain
- Responsive CSS

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

The repository README intentionally focuses on the delivered project rather than the default Create React App documentation.
